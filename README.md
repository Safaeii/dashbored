# Dashboard Management System

A modern and responsive dashboard management system built with React, Vite, and Tailwind CSS.

## 🚀 Features

- Responsive dashboard layout
- Sidebar navigation
- Dark / Light mode
- Dashboard statistics cards
- Sales reports
- Top products
- Top customers
- Recent orders
- Low stock products
- Product management
- Categories management
- Inventory management
- Sales analytics
- Settings page
- Help & Support page
- Responsive design for different screen sizes

## 🛠️ Technologies

- React
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React
- Recharts
- JavaScript (JSX)
